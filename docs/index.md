# Documents

The written half of the commons. Everything here is plain markdown in a public
repository — editable by anyone with a GitHub account and the pencil icon, and
forkable in full by anyone who wants to plant a confluence in their own bioregion.

- **[Charter](../README.md)** — what this project is, its principles, and the growth ladder. *Draft; not yet ratified.*
- **[Ecosystem Regeneration Community of the Barlavento](community.md)** — who the community is and how to join.
- **[Ecosystem Regeneration Projects](projects.md)** — the twelve participating projects, and where each one lives on the web.
- **[The River](river.md)** — the latest from every project in the community, updated hourly.
- **[Join the River](join-the-river.md)** — how to add your project. One web address; no technical skill needed.
- **[The Nursery — Terms](nursery-terms.md)** — what a member with no website of their own gets, keeps, and takes with them when they leave. *Draft; not yet in force.*
- **[WordPress Implementation Spec](wordpress-spec.md)** — living spec for the dynamic layer, evolving alongside a sandbox prototype.

## How to change any of this

Every page has a pencil icon on GitHub. Click it, edit, and GitHub will offer to
propose the change for you — no git knowledge, no local setup. Ideas that are not
yet a page belong in **Discussions**. See [CONTRIBUTING](../CONTRIBUTING.md).
