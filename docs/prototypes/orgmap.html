The social map, drawn only from what members publish about themselves

Every node and every line below was fetched from a member's own website when this page loaded. Nobody is on this map who did not put themselves on it, and no relationship is shown that the organisation did not declare from its own domain.

This is the experiment proposed in issue #14, not a replacement for the existing map. The current Social System Map centres the convening organisation because more than half its recorded edges are that organisation's own assertions about everyone else — an artifact of the data, which no amount of restyling can move. This page asks the other question: what shape does the network have when nobody is asserting it?

What you are looking at

Each circle is an organisation with a published Murmurations profile carrying the barlavento-eco tag. Each line is a https://schema.org/affiliation relationship declared in one of those profiles. Thicker lines are mutual — both organisations independently declared the other. Circle size reflects how many relationships an organisation declares and receives.

That last row is the whole argument. A map built from self-published profiles cannot contain someone who did not opt in, cannot carry a contact name nobody offered, and cannot assert a relationship nobody claimed — because nobody publishes a guess about themselves. The trade is honest and it is a real trade: this map is smaller.
